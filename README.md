# Zoom Attendance Generator

Open `index.html` in a modern browser. No installation, account, or internet connection is required for the generator itself.

## What it does

- Select a live service from the service dropdown.
- Shows the current local time and date automatically.
- Click the checkbox or locale name to mark it connected, or choose **No gathering schedule** on the right. The report uses **✅**, **❌**, and **📅** to sort the results automatically.
- Add connected individuals and remarks.
- Use **Settings** to edit the Zoom information, all labels, service options, provinces, locale names, default attendance, and no-locale notes.
- Adjust the monitoring time and copy the generated report.

Your changes are saved in the browser on that device. Use **Restore defaults** in Settings to return to the included reference setup.
